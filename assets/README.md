# Assets

Hier gehören die Bilddateien der Website hinein:

| Datei | Verwendung | Empfehlung |
| --- | --- | --- |
| `image_0.png` | Logo im Header, Favicon | PNG mit Transparenz, mind. 512 × 512 px |
| `hero-feuerwehr.jpg` | Hintergrundbild im Hero-Bereich | JPG, mind. 1920 × 1080 px, ca. 300 KB |

Personen- und Newsbilder können ergänzt werden; die Platzhalter in `index.html`
(`.person__photo`, `.card__image`) lassen sich per `background-image` oder durch
ein `<img>`-Element ersetzen.
